# Results

This folder stores output figures, tables, and metric score files generated by the experiments.

## Contents

| File/Folder | Description |
|---|---|
| `figures/` | All plots and figures used in the paper |
| `tables/` | LaTeX and CSV versions of tables from the paper |
| `scores/` | Raw metric scores (COMET, chrF, BERTScore) for all language pairs |

> **Note:** Large result files are excluded from version control. Run the notebooks to regenerate them.
